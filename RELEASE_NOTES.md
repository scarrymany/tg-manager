# TG Manager 1.0.0 — Windows 10/11

Портативная сборка: скачали zip, распаковали, запустили `TGManager.exe`.
Python ставить не нужно. Всё живёт в одной папке.

## Как запустить

1. Скачайте `TG-Manager-1.0.0-windows.zip` из Assets.
2. Распакуйте куда угодно (`D:\TG-Manager`, флешка, Desktop).
3. Запустите `TGManager.exe`.
4. При первом контейнере программа сама предложит скачать официальный
   переносной Telegram (~50 МБ) в `.\telegram\`.
5. На карточке нажмите **Папка** и положите туда `tdata`.
6. **Запуск**.

## Что внутри

- Тот же функционал, что Linux-версия на `main`: контейнеры, прокси
  HTTP/SOCKS5 на каждый аккаунт, параллельный запуск, чистка через Telethon.
- Автономная папка: `config.json`, `accounts\`, `telegram\` рядом с exe.
- Ярлык на рабочий стол — из **Настройки**.
- Прокси на Windows: обёртка ProxyChains (скачивается кнопкой, ~200 КБ).
  HTTP-прокси идёт через локальный SOCKS-мост.

## Замечания

- Windows Defender иногда ругается на упакованный PyInstaller-exe —
  это ложное срабатывание. Добавьте папку в исключения.
- Нужна 64-бит Windows 10 (1809+) / Windows 11.
- Linux-версия по-прежнему на ветке `main`.

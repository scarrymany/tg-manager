# TG Manager 1.2.1 — Windows 10/11

Портативная сборка: скачали zip, распаковали, запустили `TGManager.exe`.
Python ставить не нужно. Всё живёт в одной папке. Обновление с 1.1.0 / 1.2.0 —
просто заменить `TGManager.exe` и `TGWorker.exe`; `config.json` и `accounts\` совместимы.

## Что исправлено

- **1.2.1:** кнопки больше не «залипают» в нажатом/подсвеченном состоянии после клика
  по GitHub/Telegram (или любой кнопке, которая уводит фокус из окна). Эффект нажатия
  сделан отдельным слоем и всегда гаснет, в каком бы порядке ни пришли события.

- **«Стоп» больше не задевает чужие процессы.** Раньше поиск шёл по подстроке
  `telegram` в имени + командной строке, и при пути программы со словом *telegram*
  под остановку могли попасть `explorer.exe` / `cmd.exe`, открытые в папке контейнера.
  Теперь — только `telegram*` и `proxychains*` по имени процесса.
- **Интерфейс не подвисает.** Опрос статуса делал снимок процессов и читал командные
  строки всех процессов для каждой карточки прямо на UI-потоке. Теперь один снимок на
  опрос, в фоне, командные строки читаются только у целевых процессов. «Стоп» и удаление
  контейнера тоже асинхронные — на карточке видно «Остановка…».
- **Развернуть окно** — больше не накрывает панель задач и не вылезает за края экрана.
  Иконка «развернуть/восстановить» обновляется и при двойном клике по заголовку.
- **Прогресс-бары**: «неопределённый» режим был статичной полной полосой — теперь
  бегущий блик; скачивание Telegram/ProxyChains показывает реальный процент полосой,
  а не двумя сотнями строк в журнале.
- **Журнал задачи** живой и немодальный: строки дописываются по ходу чистки,
  главное окно не блокируется.
- **Воркер**: последние строки (`done`/`error`) больше не теряются при завершении;
  понятная ошибка, если не удалось подключиться через прокси.
- **config.json**: повреждённый файл не затирается — копия в `config.broken-<дата>.json`
  и предупреждение при старте. Дубли id / пустые поля чинятся при загрузке.
- **Удаление контейнера** останавливает идущую чистку и Telegram; если папку не удалось
  удалить (занята), об этом сообщается.
- **HTTP-прокси мост**: IPv6, таймаут подключения 15 с, корректные SOCKS-ответы об
  ошибке; при закрытии программы — предупреждение, что контейнеры с HTTP-прокси
  потеряют связь.
- **Строка прокси** понимает `http://` и `socks5://` и сама выставляет тип;
  неверный порт — ошибка вместо тихой подмены на 1080.
- Необработанные ошибки пишутся в `error.log` рядом с программой.

## Интерфейс

- Плавное появление окон, кроссфейд между «Контейнеры» и «Задачи», карточки
  появляются с лёгким сдвигом, кнопки плавно меняют цвет при наведении.
- Поля подсвечивают рамку при фокусе, чекбокс с галочкой, стрелка списка поворачивается.
- Выбор цвета карточки со свотчем. Enter/Esc работают во всех диалогах.
- Версия в статус-баре берётся из сборки.

## Как запустить

1. Скачайте `TG-Manager-1.2.1.zip` из Assets.
2. Распакуйте куда угодно (`D:\TG-Manager`, флешка, Desktop).
3. Запустите `TGManager.exe`. `TGWorker.exe` должен лежать рядом.
4. При первом контейнере программа сама предложит скачать официальный
   переносной Telegram (~50 МБ) в `.\telegram\`.
5. На карточке нажмите **Папка** и положите туда `tdata`.
6. **Запуск**.

## Замечания

- Нужна 64-бит Windows 10 (1809+) / Windows 11.
- Linux-версия (PyQt) больше не поддерживается; её последняя версия сохранена в релизе `linux-legacy`.
- HTTP-прокси работает через мост внутри `TGManager.exe`: пока программа открыта.
  SOCKS5 идёт напрямую через ProxyChains и от программы не зависит.

# TG Manager 1.3.0

## Рабочее пространство в стиле SCARP.CC

- Чёрная монохромная тема, белые основные кнопки, читаемая типографика и просторные карточки.
- Сводка контейнеров: сколько запущено, занято и не содержит tdata.
- Поиск по имени, ID, заметкам и адресу прокси. Ctrl+F открывает поиск, Escape сбрасывает фильтры из поля поиска.
- Фильтры состояния и сортировка по имени в обоих направлениях.
- Заметки в редакторе и карточках, цветовые метки для аккаунтов.

## Папки контейнеров

- Кнопка «+ Папка» создаёт группу для проекта или задачи.
- Папку можно выбрать или создать в редакторе контейнера.
- Переименование папки обновляет группу у всех её контейнеров.
- Удаление папки переносит контейнеры в «Без папки», сохраняя аккаунты и tdata.
- Пустые папки сохраняются после перезапуска. Поиск и фильтры работают внутри выбранной папки.

Папки служат для группировки в интерфейсе. Расположение `accounts/<id>/tdata` не меняется.
Существующая конфигурация поддерживается без ручного переноса.

## Проверка и сборка

Добавлены проверки поиска, состояний, группировки, сохранения папок и совместимости старой конфигурации.
Проверки WPF и Python запускаются перед публикацией в GitHub Actions.

Распакуйте архив и запустите `TGManager.exe`. Файл `TGWorker.exe` должен находиться рядом.
Для обновления замените файлы программы, сохранив `config.json`, `accounts`, `telegram` и `tools`.

# TG Manager 1.1.0 — Windows 10/11

Портативная сборка: скачали zip, распаковали, запустили `TGManager.exe`.
Python ставить не нужно. Всё живёт в одной папке.

## Что нового

- **Нативный интерфейс WPF / .NET 9** — тот же стек, что у Клип: layered-окно,
  скругление 16px, PerMonitorV2, без PyQt. Интерфейс отзывчивее на Windows 10/11.
- **Стоп** убивает Telegram (`TerminateProcess` + `taskkill /F /T`), а не прячет в трей.
- **Чистка** больше не падает на эмодзи и кириллице в названиях чатов
  (`UnicodeEncodeError: 'charmap'`). Журнал идёт в UTF-8.
- Чистка вынесена в отдельный `TGWorker.exe` (без Qt). Рядом с основным exe.

## Как запустить

1. Скачайте `TG-Manager-1.1.0-windows.zip` из Assets.
2. Распакуйте куда угодно (`D:\TG-Manager`, флешка, Desktop).
3. Запустите `TGManager.exe`. `TGWorker.exe` должен лежать рядом.
4. При первом контейнере программа сама предложит скачать официальный
   переносной Telegram (~50 МБ) в `.\telegram\`.
5. На карточке нажмите **Папка** и положите туда `tdata`.
6. **Запуск**.

## Что внутри

- Тот же функционал, что Linux-версия на `main`: контейнеры, прокси
  HTTP/SOCKS5 на каждый аккаунт, параллельный запуск, чистка через Telethon.
- Автономная папка: `config.json`, `accounts\`, `telegram\` рядом с exe.
  Ничего не пишется в AppData — можно переносить папку целиком.
- Ярлык на рабочий стол — из **Настройки**.
- Прокси на Windows: обёртка ProxyChains (скачивается кнопкой, ~200 КБ).
  HTTP-прокси идёт через локальный SOCKS-мост внутри `TGManager.exe`.

## Замечания

- Нужна 64-бит Windows 10 (1809+) / Windows 11.
- Linux-версия по-прежнему на ветке `main`.
- Старый PyQt-exe из 1.0.0 можно заменить этой папкой: `config.json` и
  `accounts\` совместимы.

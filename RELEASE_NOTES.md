# TG Manager 1.5.0

Компактный список контейнеров для десятков аккаунтов.

- Компактная карточка: одна строка с кнопками-значками и подсказками. В списке помещается 5 карточек вместо 3, шапка списка тоже стала ниже.
- Настройки → «Список контейнеров»: плотность («Обычная» / «Компактная»), высота карточки, размер и вид кнопок, набор кнопок на карточке. Изменения действуют сразу и сохраняются.
- Скрытые действия остаются в меню карточки (правая кнопка мыши); туда добавлены «Запуск» и «Стоп».
- Список виртуализирован и прокручивается по пикселям, поэтому 50+ аккаунтов листаются без задержек.
- Исправлены отступы карточек, выравнивание кнопок и прогресса на странице задач.

Поиск, папки, запуск, прокси, чистка, экспорт session и существующий `config.json` работают как прежде.

Распакуйте архив и запустите `TGManager.exe`; `TGWorker.exe` должен находиться рядом. При обновлении сохраните `config.json`, `accounts`, `telegram` и `tools`. Архив содержит лицензию Inter (`Inter-LICENSE.txt`).

`SHA256SUMS.txt` содержит SHA-256 архива. В PowerShell: `Get-FileHash .\TG-Manager-1.5.0.zip -Algorithm SHA256`.

# TG Manager

Менеджер Telegram-аккаунтов для Linux с приятным интерфейсом. Каждый аккаунт —
это отдельная карточка («окно»): даёте имя, кладёте в его папку `tdata`, нажимаете
**Запуск** — и открывается именно этот аккаунт. Можно запускать много окон
одновременно. Поддерживаются прокси **HTTP** и **SOCKS5** на каждый аккаунт.

![icon](assets/icon_256.png)

## Возможности

- 🪟 **1 карточка = 1 аккаунт.** Создаёте окно, называете, под него заводится
  своя папка. Кидаете туда `tdata` — и аккаунт готов к запуску.
- ▶️ **Запуск/стоп** каждого аккаунта, живой статус (запущен/остановлен).
- 🧩 **Много окон сразу** (флаг `-many`, отдельный `-workdir` на аккаунт).
- 🌐 **Прокси HTTP / SOCKS5** на каждый аккаунт (через `proxychains4`), с логином/паролем.
- 📦 **Переносной Telegram** внутри программы — качается одной кнопкой,
  чтобы прокси работал стабильно и не зависеть от системного/snap Telegram.
- 🎨 Тёмный современный интерфейс, иконка приложения, ярлык в меню.

## Установка (одной командой)

```bash
git clone https://github.com/scarrymany/tg-manager.git && cd tg-manager && ./install.sh
```

> Репозиторий приватный — клонирование доступно из вашего аккаунта GitHub
> (по HTTPS с токеном или по SSH).

Установщик поставит зависимости (`python3-pyqt6`, `proxychains4`), создаст ярлык
в меню приложений и подготовит запуск. После этого запускайте «TG Manager» из меню
или из терминала:

```bash
./run.sh
```

### Ручная установка зависимостей

```bash
sudo apt install python3-pyqt6 proxychains4
```

## Как пользоваться

1. **Добавить аккаунт** → задайте имя (и при желании прокси).
2. На карточке нажмите **📁 Папка** — откроется папка этого аккаунта.
3. Положите туда папку **`tdata`** (данные аккаунта Telegram Desktop).
   В карточке появится «✓ tdata на месте».
4. Нажмите **▶ Запуск** — откроется этот аккаунт.

> Telegram ждёт `tdata` **внутри** рабочей папки аккаунта — программа именно так
> и запускает: `Telegram -workdir <папка_аккаунта> -many`.

## Прокси

Прокси задаётся на карточке аккаунта (тип, `host:port`, логин/пароль) и применяется
через `proxychains4` при запуске.

⚠️ **Важно про snap.** Если Telegram установлен как **snap**
(`/snap/bin/telegram-desktop`), песочница snap не пропускает `proxychains`
(механизм `LD_PRELOAD` блокируется), и прокси **не применится**. Решение —
**переносной Telegram**:

- Откройте **⚙ Настройки → «Скачать переносной Telegram»** (качает официальный
  Telegram Desktop в папку программы `./telegram/`), либо выполните:

  ```bash
  ./get_telegram.sh
  ```

После этого программа будет запускать именно переносной бинарь, и прокси заработает.

## Настройки

- **Путь к Telegram** — автоопределение (переносной внутри программы → системный),
  либо укажите вручную.
- **Скачать переносной Telegram** — официальный tar с telegram.org.
- **proxychains** — автоопределение `proxychains4`.
- **Много окон** — флаг `-many`.

## Где хранятся данные

- Конфиг: `~/.config/tg-manager/config.json`
- Папки аккаунтов (с `tdata`): `~/.local/share/tg-manager/accounts/<id>/`
- Переносной Telegram: `./telegram/` в папке программы

## Требования

- Linux (проверено на Ubuntu), Python 3.10+
- PyQt6, proxychains4 (для прокси)

## Возможные проблемы

- **«Не найден Telegram»** — скачайте переносной Telegram или укажите путь в настройках.
- **Прокси не применяется** — используется snap-Telegram; переключитесь на переносной.
- **Аккаунт не запускается** — проверьте, что в папке есть именно `tdata`
  (а не вложенная `tdata/tdata`).

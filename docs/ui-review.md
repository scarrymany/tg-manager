# Обзор интерфейса и компактный список контейнеров

GUI в облачной среде (Linux) запустить нельзя: WPF работает только в Windows. Раскладка проверена чтением XAML,
сборкой решения (0 предупреждений) и логикой настроек (`StoreChecks` выполнены отдельно). Скриншоты и
UI-проверки `tests/TGManager.Checks --render` выполняются в CI релиза на Windows.

## Что найдено и исправлено

- **Высота карточки.** Три строки (название, мета, кнопки) занимали ~140 px, в окне помещалось 3 карточки.
- **Отрицательные отступы.** Панель кнопок имела `Margin="…,-4"` и компенсировала его отступами кнопок. Заменено обычными отступами из `ListLayout`.
- **Мета-строка.** Прокси, tdata и заметка были отдельными `TextBlock` в `WrapPanel` с фиксированными `MaxWidth`, при нехватке места строка переносилась и карточки получались разной высоты. Теперь одна строка с обрезкой и подсказкой.
- **Прокрутка 50+ контейнеров.** `ItemsControl` внутри `ScrollViewer` создавал все карточки сразу и прокручивался шагами. Теперь виртуализация и прокрутка по пикселям.
- **Скрытые действия.** «Запуск» и «Стоп» отсутствовали в меню карточки; добавлены, чтобы скрытые кнопки не лишали доступа к запуску.
- **Страница задач.** Кнопки и прогресс-бар имели разные верхние отступы (12 и 16 px), центры расходились; выровнены.
- Белый блок под списком из отчёта пользователя без Windows воспроизвести не удалось; убраны отрицательные отступы, карточка обрезается по границам (`ClipToBounds`), список стал единым скролл-контейнером с постоянным нижним отступом 16 px. **Проверьте глазами.**

## Что добавлено

- Плотность списка «Обычная» / «Компактная». Компактная карточка: одна строка, отступ 6 px, кнопки-значки 28 px с подсказками, шапка списка ниже (без подзаголовка, меньшие показатели). Оценка: ~56 px против ~138 px, то есть 5+ карточек там, где было 3.
- **Настройки → Список контейнеров:** плотность, высота карточки, размер кнопок (малые/средние/крупные), вид (с подписями/значки), набор кнопок. Смена плотности подставляет рекомендуемые значения. Сохраняется в `config.json` (`list_density`, `card_padding`, `button_size`, `button_style`, `card_buttons`) и применяется сразу после «Сохранить». Старый config читается с прежним видом; неверные значения заменяются допустимыми.
- Код: `ListLayout` (рассчитывает размеры из `Settings`), `AccountVm.Layout`, привязки в `MainWindow.xaml`, секция в `SettingsWindow`.
- Проверки: `StoreChecks` (сохранение, нормализация, старый config), `UiChecks` (соотношение высот ≥ 5/3, скрытие кнопок без перезапуска, пресет плотности в настройках).

## Что проверить глазами (Windows)

1. Главное окно в обеих плотностях при 1260×820 и минимальных 1040×560: карточки одной высоты, ничего не наезжает, нет белого блока под списком.
2. Компактная плотность с режимом «с подписями» и всеми 7 кнопками при 1040 px: название сжимается, но кнопки не вылезают за карточку.
3. Длинное имя, длинная заметка и папка: обрезка с многоточием и подсказками.
4. 50+ контейнеров: плавная прокрутка колесом и полосой, поиск и папки.
5. Настройки: смена плотности, сохранение, отмена (без изменений), скрытие кнопок и их доступность в меню правой кнопкой.
6. Запуск, стоп, экспорт session, чистка, изменение, удаление из компактной карточки.
7. DPI 125/150/200 %.
8. Скриншоты в `docs/screens` и README не обновлялись.
